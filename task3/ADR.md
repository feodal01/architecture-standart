### <a name="_qmphm5d6rvi3"></a>**Решение**
Приведите диаграммы контекста и контейнеров в модели C4. Опишите там основные компоненты и интеграции всех элементов решения.

Логика решения: поскольку нужно выдерживать требования к доступности и горизонтальному масштабированию, лучшим решением будет создание отдельного микросервиса для депозитов. Этот микросервис будет использоваться для работы со ставками. Менеджер бэк офиса все еще будет работать с АБС системой, то депозиты будут учитывваться в deposit_db, чтобы не нагружать ABC. Такэе потребуется проводить синхронизацию данных между сервисом депозитов и АВС для поддержания консистентности данных.
